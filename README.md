# OpenGame Skills (`skills` branch)

Lightweight distribution branch synced automatically from `main` for fast Skills CLI installation without cloning the full game template catalog.

## Install the main OpenGame Skill

```sh
npx skills add https://github.com/nexu-io/opengame/tree/skills --skill opengame
```

## Included Skills

- `opengame` — Main local-first OpenGame entry Skill (checks MCP, guides local Studio + stdio MCP setup via [`docs/opengame-setup.md`](https://github.com/nexu-io/opengame/blob/main/docs/opengame-setup.md), and routes to game/media workflows)
- `openmotion-game` — Specialist game-engineering Skill with 18 reference handbooks
- `openmotion-media` — BYOK & OpenDesign multimodal media generation Skill

For the full OpenGame Studio source repository, see the [`main` branch](https://github.com/nexu-io/opengame/tree/main).
